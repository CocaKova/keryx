# Internal notes

These files are the build history of the app: plan documents and pass notes, written mid-build for the
people working on the tree. They describe *intent*, and some of what they describe shipped differently
or not at all.

The user documentation is the top-level `docs/` folder, one level up:

- index: `docs/README.md`
- start here: `docs/getting-started.md`
- the rest of the pages hang off that index

Where a page here and a page there disagree, the code and `docs/` win. These notes stay in place
because other tools and notes cite these paths; nothing was moved or renamed.
